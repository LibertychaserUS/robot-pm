# 导入

文档放在云上后台的 `var/robot_pm/inbox/`，不在飞书群里发送。群消息里的文件不导入。

一个文件一次。程序先抽出文字，抽清单再把文字变成清单。已经是合法清单 JSON 的文件跳过模型和文字提取。

| 类型 | 库 | 取出什么 |
| --- | --- | --- |
| `.json` | 标准库 `json` | 清单本身。不合法就整份不投影 |
| `.md` | `markdown-it-py` | 标题层级和正文。标题变成节，正文留给抽清单 |
| `.docx` | `python-docx` | 段落文字和标题样式。标题样式变成节 |
| `.pdf` | `pypdf` | 文字层，按页拼接。没有文字层就停，不投影 |

这三个库都是开源。`python-docx` 是 MIT，`pypdf` 是 BSD，`markdown-it-py` 是 MIT。

不使用 OCR，不看版面，不把扫描件猜成字。抽不出文字的 PDF，复查单只留文件路径。

其它扩展名整份不投影，标成未识别。
