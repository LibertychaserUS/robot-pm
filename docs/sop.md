# 使用说明

这是给群里的人看的。

我是 robot PM。我按多维表格里的进度帮忙盯事情、发待办，并在该开会时发一张卡片。会议要你点同意才建立。时间用北京时间。

在群里找我，要 @ 我。点卡片按钮不用 @，那是飞书自己的交互。私聊里直接说话即可。

## 你进群之后

1. 我会 @ 你一次，说我是谁。
2. 请再 @ 我，用一句话阐述你的职责。
3. 我会发确认卡片。你点确认，我才记下。没记下之前，不拉你开会，也不把待办发给你。

一个人可以有多项职责。同一项职责可以有多个人。

## 先确认再动手

每件事有自己的步骤和进度。我会先给你计划。你点确认，我才做。

进度停在等待，超过 30 分钟，我会 @ 你，说明这次已取消。你也可以点卡片上的取消，或 @ 我并说取消，停掉还在等待的那一件。同时最多 5 个人在进行。已经满了，我会发一张卡片请你稍后再试。已经开始实施的不能取消：要么做完，要么回到原样。

各件事的步骤：

投影在后台做，不在群里确认。群里的事是：

- [收集职责](sop/role.md)
- [更新状态](sop/status.md)
- [跟进通知](sop/follow-up.md)
- [会议卡片](sop/meeting.md)
- [预定会议](sop/reserve.md)

## 更新状态

你的职责和这件事的职责相同，或者你的职责是 `pm`，才可以让我改状态。说清楚是哪一项、改成哪一种：未开始、进行中、完成、卡住。

我会先发一张确认卡片。你点同意，我才写入。大节点和发布节点的日期不能改。小节点的日期可以改，也要你点同意。标题和前置不能在对话里改。

预定会议也一样。说清楚哪一项、北京时间的开始和结束。我发确认卡片，你点同意，我才在飞书日历上预定，并把职责表里对上的人加进去。没点同意，日历上不会有这场会。

## 平时怎么找我

- 问进度：我按表格里的状态回答。
- 开会：我先给你计划。你确认后，我才把卡片发到群里。群里点同意才建会，先不办就只记下。
- 别的话题我不展开。

表里没有你的职责时，我不会猜你是谁。
